# DevOps Midterm Project – Local CI/CD Pipeline

## Project Overview

This project simulates a complete DevOps pipeline on a local machine using Flask, GitHub Actions, Ansible, and Bash scripts. It demonstrates version control, CI/CD, infrastructure as code, and basic monitoring.

---

## Stack & Tools

- **Flask** – Python web framework for demo app
- **GitHub Actions** – Continuous Integration (CI)
- **Ansible** – Infrastructure as Code (IaC)
- **Bash Scripts** – Deployment & rollback automation
- **WSL (Ubuntu)** – Local Linux environment

---

## Features Implemented

- Flask app with a form and dynamic route
- Unit test (status code check)
- GitHub Actions running tests on push
- Ansible playbook for deployment
- Blue-Green deployment with symlink switch
- Rollback mechanism (reverts to previous version)
- Health check script logging status to a file
